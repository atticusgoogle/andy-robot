SG90 Servo PWM Signal

Generates hardware-timed 50Hz PWM signals to command neck panning angles. Crucial: setting duty cycle to 0 drops torque instantly for the "Andy's Coming" limp flop!

Physical Pin: Pin 12
BCM Name: GPIO 18 (PWM0)
Connected To: SG90 Orange Signal Wire
Voltage Level: 3.3V Logic
⚠

First-Time Builder Power Rules (Brownout & Fry Prevention)

  • Rule 1 (Never 7.4V on Pi): The 18650 batteries deliver up to 8.4V fully charged. Connecting this directly to the Pi will instantly permanently destroy it. Only connect through the calibrated 5V 5A buck converter!
  • Rule 2 (Common Ground): Tie Pi GND, Battery GND, DRV8833 GND, and SG90 GND together into one single ground bus so signals share a reference zero point.
  • Rule 3 (Motor Isolation): Motor VCC (VM pin on DRV8833) takes raw 7.4V battery power, NEVER the Pi 5's 5.1V rail. This prevents motor electrical noise from corrupting Pi memory.
